# 🌍 Open-Source Universal Travel Planner (自由行與自駕遊通用行程規劃助手 — 個人使用版)

一套輕量、免伺服器（Serverless）、單一 HTML 檔案即可運作的開源旅遊行程規劃 Web App。無論您是**搭乘大眾運輸的自由行旅客（鐵路 / 地鐵 / 巴士 / 步行）**，或是**租車自駕遊旅客**，皆可透過本工具在手機（iPhone Safari / Android Chrome）或電腦瀏覽器上離線規劃行程、一鍵開啟地圖導航與管理旅途開支。

## 🎯 版本定位與說明

本開源儲存庫（GitHub Pages）提供的是 **`open_travel_planner_offline.html`（個人使用版本 / 純離線版）**：

| 版本名稱 | 適用對象 | 資料儲存與備份方式 | 取得方式 |
| :--- | :--- | :--- | :--- |
| **個人使用版本**<br>(`open_travel_planner_offline.html`) | 個人獨旅、單一裝置管理行程、注重極致隱私與 100% 離線運作的旅客 | 瀏覽器本機自動儲存 (`localStorage`) + **匯出 / 匯入 JSON 備份檔** | 直接於本 GitHub 專案下載或透過 GitHub Pages 線上開啟使用 |


## ✨ 個人使用版本 (`open_travel_planner_offline.html`) 核心功能

### 1. ⚙️ 自由行（非自駕）與自駕遊雙模式一鍵切換
* 點擊右上角 **「⚙️ 旅程設定」**，可自由修改**旅程標題**、**出發日期**與**頂部統計資訊欄**。
* **🚇 大眾運輸 / 自由行模式**：一鍵啟動 Google Maps 導航時，自動帶入大眾運輸路線（`travelmode=transit`），方便記錄地鐵出口、乘車月台、IC 交通卡與鐵路周遊券（如 JR Pass）。
* **🚗 租車自駕遊模式**：一鍵啟動 Google Maps 導航時，自動切換為汽車導航路線（`travelmode=driving`），並顯示當日預估行駛里程、自駕時數、電話定位與日本 Mapcode。

### 2. 📅 彈性天數管理與每日時間軸（Timeline）
* **自由增減天數**：點擊 **「📅 管理天數」** 即可任意新增 `Day 1 ~ Day N` 或刪除天數，系統會自動重新編號排序。
* **編輯當日概況**：點擊每日藍色橫幅上的 **「✏️ 編輯當日概況」**，可設定當日路線動線、預估交通時間、當晚入住飯店與重要預約提醒。
* **行程項目增刪改查（CRUD）**：支援隨時新增、編輯、刪除每日景點、餐廳、購物與交通行程，並按照時間自動排序；造訪後可勾選 **「標記完成」**。

### 3. 🧭 全程景點導航與全螢幕問路卡
* 自動彙整所有天數的行程地點，支援關鍵字即時搜尋與分類篩選（🏞️ 景點觀光、🍜 餐廳美食、🛍️ 購物商場、🏨 飯店住宿、🚇 大眾運輸/租車、🚗 自駕路線/休息站）。
* 每個地點皆支援一鍵開啟 **Google 導航**、**Apple 地圖**、一鍵複製電話/Mapcode，以及 **「🔍 放大問路卡」**（全螢幕放大地名與地址，方便直接出示給計程車司機、站務員或路人看）。

### 4. 🏨 交通票券、飯店住宿與航班預訂管理
* **🚇 租車 / 鐵路周遊券 / 交通預訂**：集中管理租車預約單、JR Pass、高鐵票、機場快線或一日遊憑證。
* **🏨 已訂飯店與住宿清單**：記錄入住/退房時間、飯店地址、訂單編號與聯絡電話，支援一鍵導航與全螢幕出示入住卡。
* **✈️ 航班與機票資訊**：完整記錄去回程航班編號、起降時間、航廈與免費寄艙行李限額。

### 5. 📖 旅遊攻略筆記與 🧰 隨身實用工具箱
* **📖 旅遊攻略分頁**：自由新增、編輯當地的乘車攻略、自駕交通規則、退稅須知或緊急備案。
* **💱 雙向離線匯率換算器**：支援自訂任意外幣代號（如 `JPY`、`EUR`、`USD`、`KRW`、`THB`）與本國貨幣（如 `HKD`、`TWD`）及自訂匯率，無網路也能秒速換算。
* **🎒 行前準備與行李清單**：內建完成度進度條，可自由新增或勾選必備證件與行李物品。
* **💰 旅程消費記帳本**：輸入外幣消費金額自動換算為本國貨幣，並支援依類別（餐飲、交通、購物、門票、住宿）與付款方式（信用卡、現金、IC卡/電子支付）統計總開支。
* **🗣️ 外語溝通手卡 & 🆘 緊急聯絡電話**：可自訂常用外語句子（點擊即可全螢幕放大出示）與當地報警、救護車、領事館直撥電話。

### 6. 💾 純離線本機儲存與 JSON 備份還原
* **零伺服器、極致隱私**：所有行程修改、清單勾選與記帳資料均 100% 儲存在您裝置的瀏覽器本機 (`localStorage`)，不會上傳至任何第三方伺服器。
* **JSON 匯出與匯入**：點擊右上角 **「💾 備份」**：
  * **📥 匯出目前行程與記帳資料 (JSON 下載)**：將完整行程打包下載為 `.json` 備份檔保存於手機或電腦。
  * **📤 匯入備份資料 (JSON 讀取)**：選擇先前儲存的 `.json` 檔案，即可一鍵還原所有行程與記帳紀錄。

## 🚀 如何使用與部署至 GitHub Pages

### 方式一：直接使用 GitHub Pages 線上版
1. 透過手機（iPhone Safari / Android Chrome）或電腦瀏覽器開啟本專案的 GitHub Pages 網址。
2. 點擊右上角 **「⚙️ 旅程設定」** 設定您的旅遊名稱與交通模式，即可開始規劃行程。
3. 將網頁**加入手機主畫面（Add to Home Screen）**，即可像原生 App 一樣全螢幕開啟使用。

### 方式二：下載單一檔案離線使用或自行架設
1. 下載本儲存庫中的 `open_travel_planner_offline.html`（若部署至 GitHub Pages，可將檔案重新命名為 `index.html` 推上 GitHub 儲存庫並啟用 GitHub Pages）。
2. 無需安裝任何套件（Zero Dependencies）、無需建置步驟，直接用任何現代瀏覽器開啟即可運作。
