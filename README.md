## ✨ 應用程式核心功能（個人版與協作版皆具備）

### 1. ⚙️ 自由行（非自駕）與自駕遊雙模式一鍵切換
- 點擊右上角 **「⚙️ 設定」**，可自由修改**旅程標題（支援長標題完整換行顯示）**、**出發日期**與**頂部統計資訊欄**。
- **🚇 大眾運輸 / 自由行模式**：一鍵啟動 Google Maps 導航時，自動帶入大眾運輸路線（`travelmode=transit`），方便記錄地鐵路線、車站出口編號、乘車月台、IC 交通卡（如 Suica / WOWPASS / 氣候同行卡）與鐵路周遊券。
- **🚗 租車自駕遊模式**：一鍵啟動 Google Maps 導航時，自動切換為汽車導航路線（`travelmode=driving`），並顯示當日預估行駛里程、自駕時數、車載導航電話定位與日本 Mapcode。

### 2. 📅 彈性天數管理與每日時間軸（Timeline）
- **自由增減天數**：點擊 **「📅 管理天數」** 即可任意新增 `Day 1 ~ Day N` 或刪除天數，系統會自動重新編號排序。
- **編輯當日概況**：點擊每日橫幅上的 **「✏️ 編輯當日概況」**，可設定當日路線主題、預估交通時間/里程、當晚入住飯店與重要預約提醒。
- **行程項目增刪改查（CRUD）**：支援隨時新增、編輯、刪除每日景點、餐廳、購物與交通行程，並按照時間自動排序；造訪後可勾選 **「標記完成」**。

### 3. 🧭 全程景點導航目錄與全螢幕問路卡
- 自動彙整所有天數的行程地點，支援關鍵字即時搜尋與分類篩選（🏞️ 景點觀光、🍜 餐廳美食、🛍️ 購物商場、🏨 飯店住宿、🚇 大眾運輸/租車、🚗 自駕路線/休息站）。
- 每個地點皆支援一鍵開啟 **Google 導航**、**Apple 地圖**、一鍵複製電話 / Mapcode / 地鐵出口備註，以及 **「🔍 放大問路卡」**（全螢幕高對比放大顯示當地語言地名與地址，方便直接出示給計程車司機、站務員或櫃檯人員看）。

### 4. 🏨 交通票券、飯店住宿與航班預訂管理
- **🚇 租車 / 鐵路周遊券 / 交通預訂**：集中管理租車預約單、JR Pass、機場快線（如 AREX / Skyliner）或 Klook / KKday 一日遊集合憑證。
- **🏨 已訂飯店與住宿清單**：記錄入住/退房時間、飯店當地語言地址、訂單編號與聯絡電話，支援一鍵導航與全螢幕出示入住卡。
- **✈️ 航班與機票資訊**：完整記錄去回程航班編號、起降時間、航廈與免費寄艙行李限額。

### 5. 📖 旅遊攻略筆記與 🧰 隨身實用工具箱
- **📖 旅遊攻略分頁**：自由新增、編輯當地的乘車攻略、自駕交通規則、退稅須知、快速通關（如 Visit Japan Web / ICN Smartpass）或緊急備案。
- **💱 雙向離線匯率換算器**：支援自訂任意外幣代號（如 `JPY`、`KRW`、`EUR`、`USD`、`THB`）與本國貨幣（如 `HKD`、`TWD`）及自訂匯率，無網路也能秒速換算。
- **🎒 行前準備與行李清單**：內建完成度進度條，可自由新增或勾選必備證件與行李物品。
- **💰 旅程消費記帳本**：輸入外幣消費金額自動換算為本國貨幣，並支援依類別（餐飲、交通、購物、門票、住宿）與付款方式（信用卡、現金、IC卡/電子支付）統計總開支。
- **🗣️ 外語溝通手卡 & 🆘 緊急聯絡電話**：可自訂常用外語句子（點擊即可全螢幕放大出示）與當地報警、救護車、旅遊翻譯熱線、入境處直撥電話。

### 6. 📱 專為手機單手操作優化的 UI/UX
- **底部鎖定導航列（Bottom Navigation Bar）**：五大核心分頁（📅 每日行程、🧭 行程導航、🏨 交通/住宿、📖 旅遊攻略、🧰 實用工具）鎖定於手機畫面底部，單手拇指即可秒速切換。
- **無壓迫感閱讀視野**：頂部標題欄隨頁面自然捲動收起，將螢幕空間完整留給行程內容。
- **全平台相容 JSON 匯出與匯入**：支援 iOS / Android 手機直接選取 `.json` 備份檔，並內建 **「📋 直接貼上 JSON 文字匯入 / 一鍵複製 JSON 文字」** 功能，徹底解決部分手機系統檔案選擇器限制。

## 🚀 如何使用「個人使用版本」

### 方式一：直接使用 GitHub Pages 線上版
1. 透過手機（iPhone Safari / Android Chrome）或電腦瀏覽器開啟本專案的 GitHub Pages 網址。
2. 點擊右上角 **「⚙️ 設定」** 設定您的旅遊名稱、日期與交通模式（大眾運輸 或 自駕遊），即可開始規劃行程。
3. 將網頁**加入手機主畫面（Add to Home Screen）**，即可全螢幕開啟使用，並隨時透過右上角 **「☁️ 備份」** 匯出 `.json` 檔案備份。

### 方式二：下載單一檔案離線使用或自行部署
1. 下載本儲存庫中的 `index.html`（若自行部署至 GitHub Pages，可將檔案重新命名為 `index.html` 推上 GitHub 儲存庫並啟用 GitHub Pages）。
2. 無需安裝任何套件、無需建置步驟，直接用任何現代瀏覽器開啟即可運作。
